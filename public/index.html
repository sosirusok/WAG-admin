OWNER ACCESS

GitHub로 연결

WAG 저장소에만 접근할 수 있는 토큰을 사용합니다.

처음 연결하시나요?
  1. GitHub 토큰 만들기 ↗를 엽니다.
  2. Repository access에서 Only select repositories를 고르고 WAG만 선택합니다.
  3. Repository permissions에서 Contents: Read and write만 허용한 뒤 생성합니다.
◉

토큰은 WAG-admin 저장소나 주소에 저장되지 않습니다. 선택한 경우에도 현재 브라우저 탭의 세션 저장소에만 남습니다.
